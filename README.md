
# Terraform AWS Sample

Simple Terraform project that creates one AWS EC2 instance.

## Requirements

- Terraform installed
- AWS CLI configured
- AWS Account

## Initialize

```bash
terraform init
```

## Validate

```bash
terraform validate
```

## Preview

```bash
terraform plan
```

## Deploy

```bash
terraform apply
```

Type `yes` to confirm.

## Destroy

```bash
terraform destroy
```
